# API Resource Guide - Overview

Source: https://developers.procore.com/documentation/object-model-overview

---

The Procore API Resource Guide is designed to assist developers to successfully leverage the full extent of Procore.
This guide will help you understand how all the Procore resource objects fit together when developing an integration.

The objects are grouped into three primary resource categories:

- [General Resources](object-model-general.md)
- [Company-Level Resources](object-model-company.md)
- [Project-Level Resources](object-model-project.md)

Project-level resources are further broken down into the primary Procore Product Lines:

- [Core Resources](object-model-project.md#core-resources)
- [Project Management](object-model-project.md#project-management)
- [Quality and Safety](object-model-project.md#quality-and-safety)
- [Construction Financials](object-model-project.md#construction-financials)
